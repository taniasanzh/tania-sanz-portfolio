#  Tania Sanz | Professional Portfolio

Este es el repositorio de mi portfolio web personal, una Single Page Application (SPA) diseñada para ser rápida, accesible y fácil de mantener. Refleja mi perfil híbrido: pasión por la creación de interfaces (UX/UI) respaldada por una fuerte lógica técnica.

🔗 

## 🛠️ Stack Tecnológico

- **Frontend:** React
- **Build Tool:** Vite (elegido por su velocidad y optimización en SPAs)
- **Estilos:** Tailwind CSS (enfoque utility-first para un diseño 100% a medida y escalable)
- **Despliegue:** Netlify
